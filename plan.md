# ПЛАН МИГРАЦИИ ПРОЕКТА SimpleOPDS с Python Django на Java 21 Spring Boot

## 🎯 Цель
Перенести функционал SimpleOPDS с Python (Django, SQLite/Postgres) на Java 21, с использованием Spring Boot 3.x, Postgres, Lombok, Thymeleaf, Gradle 8.14, Groovy, Flyway, с плагинами для конвертации и Telegram-бота.

**Критерии успеха:**
- Пользователь не ощущает миграцию (интерфейс, API, структура БД и поведение — максимально идентичны).
- Существующая БД seamlessly подключается к новому приложению (Postgres).
- Ядро на Java, расширения (конвертеры, Telegram) — через плагины.

## 🔧 ТЕХНИЧЕСКИЕ ЗАМЕТКИ

### Реализованные контроллеры
- `WebController` — основной UI (поиск, фильтры, каталоги)
- `OpdsController` — скачивание книг (`/opds/download/{id}/{zip}`)
- `ReaderController` — чтение книг в браузере (`/read/{id}`)

### Реализованные Book Readers
- `Fb2BookReader` — FB2 (XML парсинг, секции как страницы)
- `TxtBookReader` — TXT (автоопределение кодировки)
- `PdfBookReader` — PDF/DJVU (embed в iframe)

### Ключевые сервисы
- `BookService` — работа с книгами
- `BookFileService` — чтение файлов книг (включая из архивов)
- `BookReaderService` — роутинг на нужный BookReader
- `LibraryScanner` — сканирование директории с книгами
